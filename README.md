# 오토마타 모듈 2D 시뮬레이터

기계 요소(기어, 캠, 제네바, 링크, 랙 등)를 블록처럼 연결해 **운동의 전달과 변환**을 눈으로 확인하고,
그 구조를 그대로 **코딩 개념**(반복문, 조건문, 배열, 논리 연산)으로 번역해 보여 주는 수업용 시뮬레이터입니다.

고등학교 공학 계열 과목(공학 일반, 창의공학설계, 로봇동아리 활동 등)에서 쓰도록 만들었습니다.

## 바로 쓰기

> https://내아이디.github.io/저장소이름/
> (GitHub Pages를 켠 뒤 위 주소를 자기 주소로 바꿔 적어 두세요)

설치할 것이 없습니다. 링크를 열면 바로 돌아갑니다. 크롬, 엣지, 사파리 모두 됩니다.
태블릿에서도 손가락으로 모듈을 끌어 연결할 수 있습니다.

## 수업에서 쓰는 방법

모듈 팔레트에서 블록을 꺼내 오른쪽 출력축(●, ■)을 다음 블록의 왼쪽 입력축에 끌어다 놓으면 맞물립니다.
회전축(●)과 직선축(■)은 서로 바로 연결되지 않고, 크랭크·캠·랙 같은 **변환 모듈**을 거쳐야 합니다.
이 제약이 "운동의 형태를 바꾸려면 변환 기구가 필요하다"는 개념을 학생이 스스로 발견하게 만듭니다.

맨 끝에 **운동 그래프** 모듈을 달면 연속 회전·요동·간헐 운동·직선 왕복 중 어떤 운동인지 자동으로 판정해 줍니다.
오른쪽 패널의 **번역 코드**는 학생이 만든 기계 구조를 파이썬 비슷한 코드로 바꿔 보여 줍니다.

### 수업용 링크 만들기

주소 끝에 `?ex=번호`를 붙이면 그 예제로 바로 시작합니다. 차시별로 다른 링크를 나눠 주면 편합니다.

| 번호 | 예제 | 다루는 개념 |
|---|---|---|
| `?ex=0` | 기어로 속도 줄이기 | 기어비, 곱셈 |
| `?ex=1` | 크랭크-슬라이더 | 회전 → 직선 왕복 |
| `?ex=2` | 4절 링크 | 회전 → 요동 |
| `?ex=3` | 제네바 기구 | 간헐 운동, 반복문 |
| `?ex=4` | 조건문 캠 | 조건문 if |
| `?ex=5` | 요동 + 래칫 | 누적 연산 |
| `?ex=6` | 미션 1: 자동 분류 공정 | 반복문 + 조건문 + 배열 |
| `?ex=7` | 미션 2: 풀리 + 기어 + 크랭크 | 동력 전달 계통 |
| `?ex=8` | 반가산기 | 논리 AND, XOR |
| `?ex=9` | 전가산기 | 논리 회로 조합 |

### 학생 작품 저장과 제출

**저장 / 불러오기** 버튼은 그 컴퓨터의 그 브라우저에만 저장합니다(서버가 없는 정적 웹사이트이기 때문입니다).
다른 컴퓨터에서 이어서 하거나 과제로 제출할 때는 **JSON** 버튼을 눌러 내용을 복사하게 하세요.
복사한 텍스트를 구글 클래스룸이나 설문지에 붙여 제출하면, 선생님이 같은 JSON 창에 붙여 넣고 **적용**을 눌러 바로 열어 볼 수 있습니다.

## 조작

| 조작 | 동작 |
|---|---|
| 팔레트 클릭 / 드래그 | 모듈 추가 |
| 출력축 → 입력축 드래그 | 축 연결 |
| 연결된 입력축을 끌어내기 | 연결 해제 |
| 모듈·연결 선택 후 `Delete` | 삭제 |
| `Space` | 멈추기 / 돌리기 |
| 빈 곳 드래그 | 화면 이동 |
| 마우스 휠 | 확대 / 축소 |
| 스위치 모듈 클릭 | 0 ↔ 1 전환 |

## 파일 구성

단일 HTML 파일입니다. 외부 라이브러리 없이 캔버스와 순수 자바스크립트로만 동작하고,
글꼴만 인터넷에서 불러옵니다(차단된 망에서는 시스템 글꼴로 자동 대체되며 기능에는 영향이 없습니다).

```
index.html    시뮬레이터 전체 (이 파일 하나면 됩니다)
README.md     이 문서
```

## 수정하기

GitHub 저장소에서 `index.html`을 클릭하고 연필 아이콘을 눌러 고친 뒤 **Commit changes**를 누르면
1~2분 안에 사이트에 반영됩니다. 화면이 그대로면 `Ctrl`+`Shift`+`R`(맥은 `Cmd`+`Shift`+`R`)로 새로 고치세요.

모듈을 새로 추가하려면 `DEFS` 객체에 항목 하나를 넣고 `PALETTE`에 이름을 추가하면 됩니다.
각 모듈은 입력축·출력축의 종류(`rot`/`lin`), 계산식(`eval`), 그림(`draw`), 코드 번역(`code`)으로만 이루어져 있습니다.
